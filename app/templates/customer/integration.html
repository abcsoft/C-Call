  }'

Webhook Signature Verification

Ensure webhook calls are authentic and originate from C-Call by verifying the `X-CCAll-Signature` header against your Webhook Secret.

Python Example (Flask): 
import hmac
import hashlib

def verify_webhook(secret_key, request_body, signature_header):
    # signature_header = request.headers.get('X-CCAll-Signature')
    # request_body = raw byte content of POST request
    computed = hmac.new(
        secret_key.encode('utf-8'),
        request_body,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(
        f"sha256={computed}", 
        signature_header
    )
PHP Example: 
<?php
function verify_webhook($secret_key, $request_body, $signature_header) {
    // $request_body = file_get_contents('php://input');
    // $signature_header = $_SERVER['HTTP_X_CCALL_SIGNATURE'] ?? '';
    
    $computed = hash_hmac(
        'sha256', 
        $request_body, 
        $secret_key
    );
    return hash_equals(
        "sha256=" . $computed, 
        $signature_header
    );
}
